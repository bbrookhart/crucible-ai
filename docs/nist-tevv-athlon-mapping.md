# NIST TEVV-Athlon mapping

NIST AI 200-2 is an **Initial Public Draft** as of 2026-08-28. CRUCIBLE does not claim NIST endorsement,
certification, compliance, or interoperability.

| CRUCIBLE concept | TEVV-Athlon use |
|---|---|
| Research question and measurement case | Defines the assessment objective and intended evidence |
| Task, model, agent, tool, and environment registries | Makes customized evaluation components explicit |
| Bounded evaluation event | Executes an observable system interaction under declared constraints |
| Ground-truth scorer and metrics | Produces measurement data tied to concepts of interest |
| Evidence package and reviewer guide | Supports interpretation, reproduction, and limitation review |
| Safety and contamination models | Records evaluation risks that can invalidate conclusions |

CRUCIBLE primarily contributes evidence to AI RMF MAP and MEASURE and can inform MANAGE. It is not an
AI RMF compliance checklist.

Official reference: [The TEVV-Athlon Framework for Evaluating AI Systems](https://www.nist.gov/artificial-intelligence/ai-research/tevv-athlon-framework-evaluating-ai-systems).
