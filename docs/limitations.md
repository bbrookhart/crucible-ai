# Limitations

CRUCIBLE v0.1 establishes a tested measurement architecture and deterministic public validation pack.
It does not establish frontier-model cyber capability, operational effectiveness, model safety, human
uplift, absence of contamination, or generalization to production systems.

The local adapter supports only a loopback OpenAI-compatible endpoint; endpoint weights may not be
pinnable. Public S1 fixtures are small and transparent. BLACKBOX lacks HSM custody and remote attestation.
Evidence hashes lack third-party signatures. Docker isolation depends on the host kernel. No distributed
sequestered task set, dynamic S3 lab, LONGFORM pack, external reproduction, or governed human study is
included in this release.
